# 『大フィフリス』分析：コードブック作成のための引き継ぎメモ

（Claude Code でのやり取りの要約。2026-10-11）

## 研究の目的と前提

- 史料：アブドゥルハイイ・カッターニー（1382/1962年没）『فهرس الفهارس والأثبات ومعجم المعاجم والمشيخات والمسلسلات』。イフサーン・アッバース校訂（ダール・アル＝ガルブ・アル＝イスラーミー、第2版、1982年）。シャーミラ（Shamela）の電子テキストをOpenITIのmARkdown形式にしたもの（OpenITI/1400AH, 1382Kattani.FahrasFaharis.Shamela0001037-ara1）。
- 目的：「ファフラサ型」文献とその著者が、時代と地域にどう分布しているかを分析する。著者の属性（法学者・神学者・スーフィーなど）、作品の内容（ハディースのみか、それ以外の分野を含むか）、分量も変数にしうる。ただし『大フィフリス』が記録している範囲に限られる。
- 前提：イスラーム世界の知の流通そのものではなく、**カッターニーの視座から集められた伝承の記録**として分析する。カッターニーの偏りは補正すべき誤差ではなく、分析の対象として扱う。

## テキストの構造（確認済み）

- 番号付きの見出しは1,222件。二つの番号系列がある。
  - 人名見出し `### $`（番号1〜662）：「من اسمه أحمد」…「الكنى」。例：「أحمد الأزدي: … أروي فهرسته …」
  - 書名見出し `### $DIC_BIB$`（番号1〜563）：「ما عرف اسمه من الفهارس」。例：『الأمم لإيقاظ الهمم』
- 参照のみの見出し `### $$$` が208件ある（例：「أحمد بن علي ابن حجر: هو الحافظ (انظر حرف الحاء)」）。
- 序論部には『アワーイル』（كتب الأوائل、DIC_BIB 1〜12）と『アルバウーン』（DIC_BIB 13〜15）がある。世紀別のハーフィズ名簿（`### $$$$`、5件）もある。
- 1項目の長さ：中央値は約80語、上位10%で約490語、最長は約4,600語。
- ほとんどの項目は同じ順序で書かれている。①著者の紹介（名・ニスバ・称号・生没年）→ ②作品の評価や内容 → ③カッターニーに至る伝承経路（أرويه / نرويه / ح: …）。
- 校訂者の脚注は本文に入っていない（「(1)」などの番号だけが残っている）。

## データ上の問題（確認済み）

- 番号の誤り：DIC_BIBでは15・233・392が重複している。`$` では253が重複し、140が733と誤記され、65・80・184などが欠けている。
- タグの誤り：番号付き見出しのすぐ後の本文が `$$$` と誤ってタグ付けされた例が12件ある（例：#283 クーラーニー）。行の途中に誤った `$$$` が付いて項目が切れている例もある（スユーティーの項目）。`$$$` のうち「انظر」を含まないものが18件あり、こうした誤りの候補である。
- 年号の省略：「ولد سنة 96」は996年の意味（#5 イブン・アル＝カーディー）。
- 誤入力：「عام1.32」は1032年と思われる（#4 アフマド・バーバー）。
- ニスバの混在：伝承経路にも人名が多く出てくる（例：「الزبيدي」の大半は伝承経路に出るムルタダー・ザビーディー）。著者の属性は**著者紹介の部分に限って**取り出す必要がある。
- 没年を表す決まった表現が見つかった項目は約35%にとどまる。外部の典拠（OpenITIの著者URI、Wikidata、ズィリクリーの『アアラーム』）で補う必要がある。

## 分析の単位：項目・作品・人物

- **項目**：印刷版で番号付きの見出しを持つ記述単位（案）。「系列＋番号」で識別する。参照のみの見出しは項目に数えず、参照として別の表に記録する。（番号が校訂者によるものかは要確認）
- **作品**：ファフラサ型の書物。
- **人物**：作品の編者、および見出しに立てられた人物。

```
項目 ──記述する──▶ 作品（0〜n点） ──編者──▶ 人物
  └───────見出しの人物──────────▶ 人物
```

ずれる例：

| ずれ方 | 例 | 項目 | 作品 | 人物 |
|---|---|---|---|---|
| 一つずつ対応する | 人名#1 アズディー | 1 | 1（題名なし） | 1 |
| 1項目に複数の作品 | 人名#283 イブラーヒーム・クーラーニー：『الأمم』『جناح النجاح』「الثبت الأوسط والكبير」 | 1 | 4 | 1 |
| 1人物が複数の項目に | クーラーニー：人名#283、書名#16『الأمم』、『جناح النجاح』の項目 | 3 | 4 | 1 |
| 見出しの人物と編者が別人 | 人名#18 イブラーヒーム・アラウィー：師と伝承をまとめたのは孫のアブー・アル＝カースィム | 1 | 1 | 2 |
| 書物ではなく伝承の全体 | #18「أروي ماله من مروي」 | 1 | 0？ | 1 |

何を数えるかで分かるものが違う：
- 項目 → カッターニーの整理の仕方と、どれだけ注意を向けたか
- 作品 → カッターニーが知っていたファフラサ型文献の分布
- 人物 → ファフラサの著者たちの分布と属性

## 候補の変数（コードブックで定義する）

| 変数 | 内容 | 想定する方法 |
|---|---|---|
| ジャンル語 | فهرسة / ثبت / برنامج / مشيخة / معجم / إجازة / مسلسلات / أوائل / أربعون | 規則＋LLM |
| 著者 | 名・クンヤ・ラカブ・ニスバ・生没年（ヒジュラ暦）とその根拠（本文か外部の典拠か） | LLM＋外部の典拠 |
| 地理 | 出身と居住を区別する（「الفاسي ثم المدني」「نزيل」「دفين」） | LLM＋al-Thurayya地名辞典 |
| 属性 | カッターニーが与えた称号をそのまま記録する（الحافظ / المحدث / المسند / العارف / الفقيه …）、法学派、タリーカ | LLM |
| 作品の内容 | ハディースのみか、法学・神学・スーフィズム・読誦学を含むか、ムサルサラートやアワーイルを含むか | LLM |
| 作品の分量 | كراريس / مجلد / أوراق の記述、刊本か写本か | LLM |
| カッターニーとの関係 | 伝承しているか（أرويه）、実見したか（وقفت عليه）、所蔵しているか（عندي / بخطه）、伝承経路の長さ | LLM |
| カッターニーの情報源 | 引用している典拠（例：「قال في البدور الضاوية」） | LLM |
| 項目の分量 | 語数（カッターニーの注意の目安） | 自動 |

LLMで取り出すときは、値ごとに根拠となるアラビア語の箇所を引用させる。無作為に選んだ一部を人手で検証する。

## コードブックで決めること

1. 序論部の『アワーイル』『アルバウーン』15件を、分析対象のファフラサ型に含めるか。
2. 「ما له من مروي」のように書物を特定しない伝承の全体を、作品と数えるか（数えない場合は「対象の種類」という変数を設ける：独立した書物／他の書物の一部／伝承の全体／不明）。
3. 名前だけ挙がって独立した項目のない作品を、作品の表に入れるか（入れるなら「言及のみ」の印を付ける）。
4. 編者と見出しの人物が違うとき、どちらを分布の軸にするか（両方を記録しておくことを推奨）。
5. 称号（スーフィー・法学者など）の分類を、カッターニーの語彙のまま使うか、上位の区分にまとめるか。まとめるなら、その対応表をどう作るか。
6. 時代区分（ヒジュラ暦の世紀ごと。カッターニー自身の世紀区分と比べられる）と地域区分（マグリブ／アンダルス、エジプト、ヒジャーズ、シャーム、イエメン、イラク、インド、ルームなど）。
